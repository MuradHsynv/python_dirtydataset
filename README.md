# Sales Data Cleaning Pipeline

A Python-based data processing pipeline that transforms raw, sparsely populated matrix sales data into a normalized, tidy CSV format while generating aggregate summary statistics.

## Features

* **Wide-to-Long Transformation:** Utilizes `pandas.melt()` to convert structural column headers into row-level variables.
* **Data Normalization:** Parses combined category strings (e.g., `consumer_first_class`) into distinct `Segment` and `Ship Mode` columns.
* **Automated Cleansing:** Drops redundant summary rows (`Grand Total`), aggregate columns (`_total`), and cleans empty records (NaNs).
* **Statistical Aggregation:** Automatically calculates order counts, total sales, average order value, and maximum order value grouped by segment and shipping mode.

## Prerequisites

* Python 3.7+
* `pandas` library

## Installation

1. Clone the repository and navigate to the project directory.
2. Install the required data manipulation dependency:
```bash
pip install pandas
```

## Usage

1. Save your raw dataset in the root directory as `raw_data.csv`.
2. Execute the cleaning script:
```bash
python data_cleaner.py
```
3. Review the terminal output for the statistical analysis breakdown.
4. Retrieve the normalized dataset from the newly generated `cleaned_sales_data.csv` file.

## Project Structure

* `data_cleaner.py`: The core data processing script containing the `clean_and_analyze_sales_data` function.
* `raw_data.csv`: The input data matrix (must be present before execution).
* `cleaned_sales_data.csv`: The normalized, formatted output file generated by the script.
